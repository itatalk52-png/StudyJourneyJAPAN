Study Journey JAPAN Ver.2.2.5 Beta16

新機能:
- Friends右上にMISSIONのCOM./IND.と同系統の「TOTAL / TODAY」スライド式切替を追加
- TOTAL: 累計ポイント(totalPoints)順のランキング
- TODAY: 今日の簿記勉強時間(todayMinutes)順のランキング
- TODAYでは今日0分の利用者は順位表示を「―」にし、下側へ配置
- 切替は取得済みランキングデータを端末内で並び替えるため、追加通信なし
- 最後に選んだTOTAL/TODAYを端末に保存
- TODAY表示では今日の勉強時間を視覚的に少し強調
- 最上部の自分カードも選択モードに合わせた強調へ連動

Apps Script更新:
不要です。既存rankingV2のtodayMinutes / totalPointsを利用します。

反映方法:
1. ZIPを解凍
2. StudyJourneyJAPANへ上書き
3. Commit to main
4. Push origin
5. アプリを完全終了して再起動
