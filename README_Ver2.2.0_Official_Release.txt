【主な新機能】
- Timer画面に「時間の修正」ボタン
- 学習日を選択して、その日の記録を減らす
- 時・分・秒を指で上下になぞるスワイプ式ホイール
- 中央吸着、選択数字の強調、対応端末での振動
- 修正前より長い時間には変更不可
- 修正履歴を学生本人が確認可能

【安全対策】
- 6時間以上の連続計測を自動加算せず確認
- 24時間以上は安全のため自動停止
- studyDateが属する週へ集計
- recordIdによる二重送信防止
- 修正後に学習時間・ポイント・Friends・カレンダー・メダルを再計算

【反映方法】
- 正式版のStudyJourneyJAPANリポジトリへ上書き
- Commit to main
- Push origin
